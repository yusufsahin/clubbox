## Agora URLs

No dedicated Agora token-refresh endpoint was captured. Clubbox renews RTC tokens by calling the observed `join_channel` route again and passing the new token to Agora `client.renewToken` on `token-privilege-will-expire`. If renew fails or `token-privilege-did-expire` fires, it falls back to leave + rejoin Agora (still using `join_channel` for the token). Log shape: `[AgoraRTC] token-privilege-will-expire afterMin=N` / `token-privilege-did-expire afterMin=N` (minutes since join — first evidence of token lifetime). Do not invent a refresh-only API.

No Agora URLs captured yet. The app id, channel, and uid keys are recorded on `join_channel` in `web-api.md` when that response includes them.

## Room channels and actions (community sources, 2026-10-11)

Not in the clubhouse.com bundle (the web room UI only parses `channel_message` / `channel_reaction`). Taken from two open-source clients that read the live PubNub stream:
[grishka/Houseclub `VoiceService.java`](https://github.com/grishka/Houseclub) (Android) and
[seovchinnikov/clubhouse-web `JoinChannel.vue`](https://github.com/seovchinnikov/clubhouse-web) (web).
Evidence level: **community** — confirm with the request/realtime log in live use.

Subscribe (`/v2/subscribe/{sub_key}/{channels}/0`, `auth` = `pubnub_token`, `uuid` = my user id; the v2 answer is `{ t: { t, r }, m: [ { c, d } ] }` — send `tt` and `tr` back):

- `users.{myUserId}`
- `channel_user.{channel}.{myUserId}` — personal room events (speaker invites)
- `channel_all.{channel}` — room-wide events
- `channel_speakers.{channel}` — moderators only (subscribing without the grant fails the request)

Payloads carry `action` and `channel` (ignore messages whose `channel` is another room):

| action | user | Clubbox effect |
| --- | --- | --- |
| `join_channel` | `user_profile` | add listener |
| `leave_channel` | `user_id` or `user_profile.user_id` | remove |
| `remove_from_channel` | `user_id` | remove |
| `raise_hands` | `user_profile` | hand up |
| `unraise_hands` | `user_id` | hand down |
| `add_speaker` | `user_profile` | to stage |
| `remove_speaker` | `user_id` | to audience (drops moderator) |
| `make_moderator` | `user_id` | moderator (on stage) |
| `invite_speaker` | `from_user_id`, `from_name` (inviter) | invite **me** |
| `end_channel` | — | room ended |
| `new_channel_message` | same as ticker `channel_message` | chat line |
| `new_channel_reaction` | same as ticker `channel_reaction` | reaction toast |
| `change_handraise_settings` | `is_enabled`, `handraise_queue_setting`, `handraise_permission` | update stage access |
| `update_user_capabilities` | `can_*` booleans | merge into `user_capabilities` |
| `cumulative_count_update` | `num_ever` | set `num_ever` (separate from live `num_all`) |
| `update_speaker_call_status` | `user_id`, `is_on_call`, `audio_profile` | per-user on-call + music badge |
| `uninvite_speaker` | `user_id` | same as `remove_speaker` (to audience) |
| `set_channel_title` | `title` or `topic` | patch channel `topic` |
| `emoji_reaction` / `gif_reaction` | same family as `new_channel_reaction` | reaction toast |

Mute and "speaking" state come from Agora (remote audio mute / volume), not PubNub.
Room mutations go through `applyRoomEvent` (pure reducer).

The production PubNub keys and Agora app id are the config block with a live Stripe key in the bundle; clubhouse-py's constants (`AGORA_KEY`, `PUBNUB_*_KEY`) match that block.

## Troubleshooting

Chromium's P2P socket manager prints these while Agora is choosing a gateway. They are not a failed join. The client still reaches `CONNECTED` through another candidate (Phase 23: red herring).

- `Failed to resolve address for <host>.edge.agora.io., errorcode: -105` — note the trailing dot. The socket manager is resolving one Agora hostname candidate as an FQDN. That candidate has no AAAA record, so the IPv6 lookup returns -105.
- `socket destroyed` — the same attempt closing the socket that failed that lookup.

Do not add DNS workarounds, host-resolver rules, or a bare-IP gateway. Those were measured and made the join worse. The measurement is in `docs/history/agora-voice-dns-fix.md`.
